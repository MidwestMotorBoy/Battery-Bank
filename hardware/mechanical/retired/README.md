# Retired mechanical outputs

This folder held the generated files for the two enclosures the cup replaced: the top-cap tube (to 2026-10-18) and the side tray with its aluminium cover (2026-10-18 to 2026-10-21), including the cover's STEP/DXF/marking files, the renders, the layout comparison and the FDM home-print kit. None of it was to be built, and all of it (60 files, about 38 MB) was removed on 2026-10-29. Get any of it back from git: it is all at Production commit `5cf521e`, e.g. `git show 5cf521e:hardware/mechanical/retired/monolith_side_hero.png > hero.png`, or `git checkout 5cf521e -- hardware/mechanical/retired`.

The side-tray-only scripts went at the same time (`monolith_assembly_steps.py`, `monolith_standoff_detail.py`, `monolith_standoff_zones.py`, `monolith_print_kit.py`, `monolith_cover_label.py`, and the render entry points of `monolith_side_renders.py` and `monolith_render.py`); those two modules stay as helper libraries for the cup scripts.

`monolith_shell.py` and `monolith_parts.py` still write the retired geometry here when run (`monolith_shell.RETIRED`), because the live board outline `monolith_side_pcb.dxf` comes from the same run. Everything here except this README is git-ignored. The design notes for these layouts are in [`docs/archive/side-tray-mechanical.md`](../../../docs/archive/side-tray-mechanical.md); the current enclosure is in [`docs/mechanical-design.md`](../../../docs/mechanical-design.md).
